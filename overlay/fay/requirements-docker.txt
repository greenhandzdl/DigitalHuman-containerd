# Fay 容器化最小依赖集 —— 不改动 fay 仓库，本文件只存在于 containerd/overlay/。
#
# fay 与 origin-fay 两个实例共用这一份（Dockerfile 的 REQS_DIR 默认指向 overlay/fay）：
# fork（chuan918/Fay）是上游 v4.8.1 的直接后代，只多了 .gitignore / config.json /
# explain.md 三处非代码改动，Python 源码与上游逐字节相同，所以依赖集也只剩一份。
#
# 依据：对 39 个启动链文件的 AST 静态扫描（模块级 import），而非上游那份
# requirements.txt（它把 ASR/TTS 全供应商、桌面 GUI、知识库索引器都混在一起）。
# 因此**不装** torch / sentence-transformers / chromadb / opencv / PyQt5 / pygame，
# 镜像从数 GB 降到约 600MB。代价与边界见 containerd/README.md「未覆盖能力」。

# --- Web / 服务框架 (gui/flask_server.py, core/wsa_server.py) ---
flask~=3.0.0
flask-cors
flask-httpauth
gevent
websockets~=10.4
websocket-client
# uvicorn 由 mcp 带进来；>=0.35 只支持 websockets>=13 的新 API
# (uvicorn/protocols/websockets/auto.py 直接 import websockets.server.ServerProtocol)，
# 与上游 websockets~=10.4 冲突 → MCP SSE(8765) 线程起不来。实测 0.34.3 正常。
uvicorn<0.35

# --- LLM 大脑 (llm/nlp_cognitive_stream.py, llm/execution_manager.py) ---
# 只装 langchain-core + langchain-openai，不装 langchain 伞包：
# 伞包会把 langgraph 解析到最新，而 langgraph>=1.2.11 依赖 langgraph-sdk>=0.4.2，
# 后者要求 websockets>=14 —— 与上游 requirements.txt 的 websockets~=10.4 冲突
# （core/wsa_server.py:7 用 websockets.legacy，
# core/socket_bridge_service.py:44 用两参数 handler）。
# 启动链实际只 import langchain_openai / langchain_core.messages；
# utils/openai_api/langchain_openai_api.py 用到 langchain.chains 但全仓无人 import。
#
# 不装 langgraph：全仓（chuan918/Fay@f702528 == 上游 v4.8.1 的 Python 源码）grep 不到
# 一处 langgraph import，上游 requirements.txt:28 那行是摆设。
langchain-core
langchain-openai
openai
httpx
requests
urllib3
tenacity

# --- MCP 客户端/服务端 (faymcp/*) ---
# 上游裸 `mcp` 解析到 2.2.0，而 2.x 的 mcp.server.Server 换成了高层 MCPServer，
# 没有低层的 @server.list_tools() 注册装饰器。仓库里 6 个文件按 1.x 写
# （faymcp/mcp_server.py:26、
# mcp_servers/{logseq,schedule_manager,window_capture,yueshen_rag}/server.py、
# test/mcp_stdio_example.py），2.x 下全部 AttributeError，开机 autostart 的「tools」
# 必失败。钉 1.x，实测解析 1.30.0。
mcp>=1.2,<2

# --- 语音输出：tts_module 取非 ali/gptsovits/volcano 时走 ms_tts_sdk(edge_tts) ---
# azure SDK 在 tts/ms_tts_sdk.py 是模块级 import，必须能装上；
# 没有 ms_tts_key 时实际走 edge_tts（免费、需外网到 speech.platform.bing.com）。
edge-tts
azure-cognitiveservices-speech
pydub
# main.py:86 无条件 from asr import ali_nls → asr/ali_nls.py:9 需要 aliyunsdkcore，
# 即使不用阿里云 ASR 也必须装（上游 requirements.txt 里就有）。
aliyun-python-sdk-core

# --- 音频采集：pyaudio 在 fay_booter.py:19 / gui/flask_server.py 是模块级 import，

pyaudio
numpy
